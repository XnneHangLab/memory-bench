SPECIFICATION 02 / PROTOCOL, SCORING & LATENCY

怎么测才公平：对照、判分与耗时账本

没有 Baseline 的分数无法证明增量价值，不算端到端延迟和写入消耗的榜单在工程上失真。这一页规定每轮评测必须遵守的执行协议、对照组与计分纪律。

01 / EXECUTION PROTOCOL

把长期相处变成可复查、防作弊的实验

  1. 建立起点：固定 user_seed 与 companion_persona；系统只允许看到明确暴露的初始设定与会话，禁止偷看检查点答案或未说出口的内心独白。
  2. 按时间流送入会话：依次注入日常聊天、共同事件、条件更新、互相矛盾的说法与日常噪音填充，不在前期泄露后续检查点。
  3. 穿插多种检查点：混合“不提示回忆的自然续聊”“直接问答”“无记忆对照”和“边界陷阱”。每次探针前保存状态快照，避免测试问题本身污染后续记忆。
  4. 运行配对历史（反事实检验）：保持当前这句消息一模一样，只替换过去的关键经历（如昵称或约定），观察回答是否跟着合理变化；同时加一组无关历史变动，检验系统是否过度敏感。
  5. 真正触发记忆整理与重启：按公开规则执行上下文窗口截断、摘要压缩、记忆合并或服务重启后再提问——单纯把系统时钟改到“三年后”不算真正考过遗忘。
  6. 全程留痕：记录输入、召回片段、工具调用、最终输出、token 用量、各环节耗时与失败报错，以便定位问题出在“没记住”“没召回”还是“模型不会用”。

02 / REQUIRED BASELINES

四组必需对照（缺一不可）

在 Tier S (32K) 下，第 2 组能完整吃进全部历史，用来验证“框架有没有反而把事情搞砸”；在 Tier M (160K) 和 Tier L (512K–1M) 下，第 2 组则会真实面对窗口截断与延时/成本压力，用来检验框架是否真的比裸模型更有性价比。

对照组系统能看到什么它负责回答的真相
1. 当前会话（无记忆）固定角色卡 + 当前这一轮会话不靠过去历史时，模型只凭常识猜测能蒙对多少？
2. 原始历史入上下文固定角色卡 + 窗口内完整原始历史 + 当前会话核心 Baseline：直接读原始聊天记录，是不是已经比记忆框架更准、甚至更便宜？
3. 简单检索固定角色卡 + BM25 或普通向量检索片段 + 当前会话复杂记忆架构（图谱/多智能体/摘要树）相比基础 RAG 到底多赢了什么？
4. 目标记忆框架固定角色卡 + 待测框架的写入与检索结果 + 当前会话在真实成本和延迟约束下，这套方案到底值不值得上？

对照时须统一回答模型、采样参数、工具权限与输出预算；记忆框架内部额外调用了什么模型须单独披露。超出窗口时必须同时报告“窗口允许的最大完整历史”和“与框架同等的输入 token 预算”，绝不把静默截断伪装成完整历史；另可加设“人工正确证据（Oracle）”诊断组，定位瓶颈究竟在检索还是在生成。

03 / SCORING RULES

分数必须能追溯到具体行为，不和稀泥

每个检查点在出题时就必须写明 visible_evidence、must_satisfy、forbidden 以及 0–4 分行为锚点；未考查的维度标注 N/A。

通用 0–4 分锚点（每道题仍需配合具体行为判据）
分值对应表现
0 分与核心证据直接冲突、编造没发生过的共同经历，或违反该题明确约束（如泄露出要求遗忘的内容）。
1 分仅给出泛化、礼貌或模板化的表面回应，关键条件与记忆线索大多未落地。
2 分记住了部分碎片，但遗漏了决定互动是否成立的重要条件、主体归属或最新状态。
3 分满足全部核心事实与关系要求，但在语气自然度或细节衔接上有轻微瑕疵。
4 分核心证据、最新条件、人格连续性与上下文适切度全部满足，无多余机械感。

聚合与纪律：先在单条轨迹内按适用检查点求平均，再对覆盖该维度的轨迹等权平均，并旁列轨迹数、有效检查点数、缺测与超时数。禁止按六维面积直接排名。运行超时或系统报错必须保留并计入主结果失败率，不得事后改写成 N/A。事实、时间、归属与更新按证据硬核对；人格连续性、自然度与关系发展由隐藏系统名称的评审独立打分，若辅助使用 LLM 裁判，须先校准其与人工判断的一致性。

04 / LATENCY & COST

真实陪伴还要等多久、花多少钱？

质量雷达图只回答“答得好不好”，工程上必须同时摊开延迟与成本账本，绝不用一个混合总分掩盖代价：

  • 首个有效回复 & 完整回复耗时（p50 / p95）：从用户发出消息开始计时，记录中位数、长尾 95 分位与超时率。“正在思考…”等占位提示不计为有效回复。
  • 检索与 Agent 搜索全开销：完整包含查询改写、embedding、图谱遍历、重排、agent 多轮决策与读文件耗时，并记录工具调用轮数解释瓶颈来源。
  • 写入到可检索的时间差：用户刚纠正了一件事，下一句话能不能立刻用上？异步写入接口返回“成功”，不代表记忆已经真正生效。
  • 全链路 Token 与存储账单：不仅算回答阶段输入，必须把记忆抽取、摘要合并、冲突更新、推理 token、embedding 与存储开销一起算清楚。
  • 透明运行环境：披露硬件规格、API 地区、并发数、缓存冷热、具体模型版本与网络条件。
